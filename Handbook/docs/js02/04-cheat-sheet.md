# JS02 — Cheat Sheet UTS

- `display: flex` → layout satu dimensi.
- `display: grid` → layout baris/kolom.
- `justify-content` → posisi sepanjang main axis Flexbox.
- `align-items` → posisi sepanjang cross axis.
- `gap` → jarak antar item.
- `padding` → ruang di dalam border.
- `margin` → ruang di luar border.
- `border` → garis pembatas.
- `box-shadow` → bayangan.
- `:hover` → pointer berada di elemen.
- `:focus` → elemen sedang mendapat fokus.
- `var(--nama)` → memakai CSS variable.
- `@media` → aturan berdasarkan kondisi ukuran/media.

### Ingatan cepat

```text
HTML = struktur
CSS  = tampilan
Flex = susun item dalam satu arah
Grid = susun item dalam baris + kolom
```
