# Jobsheet 05 — CSS Pendukung JavaScript

CSS mendukung fitur JavaScript melalui selector/class tertentu.

Contoh hubungan:

```text
JavaScript mencari elemen
        ↓
ID / class harus sesuai HTML
        ↓
CSS mengatur tampilan elemen tersebut
```

Dokumentasi source mencakup tabel responsive, hamburger, pesan error, search box, navbar mobile, card statistik, dan form mobile.
