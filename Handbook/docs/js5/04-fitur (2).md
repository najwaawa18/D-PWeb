# Jobsheet 05 — Perubahan HTML

Jobsheet 05 menambahkan kebutuhan agar halaman dapat berinteraksi dengan JavaScript dan lebih nyaman pada mobile.

Perubahan yang didokumentasikan:

1. Penambahan viewport.
2. Tombol menu pada header.
3. Kolom pencarian pada daftar buku dan anggota.
4. Class `table-responsive`.
5. Class khusus pada tombol Hapus.
6. `id="form-tambah"` pada form.
7. Penyesuaian `required`.
8. Pemanggilan file JavaScript.
