# Jobsheet 02 — Header, Navbar, dan Flexbox

Header digunakan untuk identitas SIMPUS-Mini dan navigasi. Flexbox membantu menata elemen secara horizontal dan memberi jarak antarelemen.

```css
header {
    display: flex;
    align-items: center;
    justify-content: space-between;
}
```

### Cara mengingat

- `display: flex` → aktifkan Flexbox.
- `align-items` → posisi pada arah silang.
- `justify-content` → pembagian posisi pada arah utama.
