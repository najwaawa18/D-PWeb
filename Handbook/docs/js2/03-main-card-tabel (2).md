# Jobsheet 02 — Konsep CSS Dasar

## 1. Gambaran Umum

Jobsheet 02 menambahkan CSS ke SIMPUS-Mini agar halaman HTML memiliki tampilan yang lebih teratur.

## 2. Hal yang Dipelajari

- Reset/mengatur style dasar.
- Warna dan typography.
- Header dan navbar.
- Layout menggunakan Flexbox.
- Main, section, dan card statistik.
- Tabel.
- Form.
- Footer.

## 3. Pola Dasar

```css
* {
    box-sizing: border-box;
    margin: 0;
    padding: 0;
}

body {
    font-family: Arial, sans-serif;
}
```

Reset sederhana membuat ukuran elemen lebih mudah dikendalikan.
