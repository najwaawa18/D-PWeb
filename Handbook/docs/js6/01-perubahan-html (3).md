# Jobsheet 06 — `anggota.js`

`anggota.js` menggunakan konsep yang sama dengan `buku.js`, tetapi sumber datanya adalah:

```text
../data/anggota.json
```

Data yang ditampilkan:

- `no_anggota`
- `nama`
- `alamat`
- `no_hp`

Baris tabel dibuat secara dinamis menggunakan `createElement()`, `innerHTML`, dan `appendChild()`.
