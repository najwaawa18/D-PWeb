# Jobsheet 03 — Tabel Responsive

Tabel perlu diberi perlakuan khusus karena jumlah kolom dapat membuat halaman melebar pada layar kecil.

Konsep yang digunakan pada dokumentasi Jobsheet adalah membungkus tabel dan mengatur overflow agar tabel tetap dapat diakses pada layar sempit.

```css
.table-responsive {
    overflow-x: auto;
}
```

Dengan cara ini, pengguna dapat menggeser area tabel secara horizontal ketika diperlukan.
