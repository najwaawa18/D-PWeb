# Jobsheet 03 — Responsive Design

## 1. Gambaran Umum

Jobsheet 03 melanjutkan styling dengan fokus pada **responsive design**, sehingga tampilan dapat menyesuaikan ukuran layar.

## 2. Konsep Utama

Media query digunakan untuk menerapkan aturan CSS pada ukuran layar tertentu.

```css
@media (max-width: 768px) {
    /* aturan tablet */
}

@media (max-width: 480px) {
    /* aturan mobile */
}
```

## 3. Tujuan

- Tabel tetap dapat dibaca.
- Navigasi menyesuaikan layar.
- Layout tidak terlalu lebar pada mobile.
