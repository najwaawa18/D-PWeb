# Jobsheet 03 — Hamburger Menu

Pada tampilan kecil, navbar dapat diubah menjadi tombol hamburger. Source Jobsheet 03 menggunakan pendekatan checkbox untuk membantu menampilkan/menyembunyikan navigasi.

Konsep sederhananya:

```text
checkbox tidak dicentang → menu tersembunyi
checkbox dicentang       → menu ditampilkan
```

CSS kemudian menggunakan selector dan media query untuk mengatur perilaku tersebut.
