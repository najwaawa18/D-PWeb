# 00 — Cara Belajar dari Handbook

## Tujuan

Handbook ini bukan sekadar kumpulan definisi. Polanya dibuat supaya saat lupa satu bagian, kamu bisa menelusuri hubungan **HTML → CSS → Responsive → UI/UX → JavaScript → JSON/Fetch → Deployment**.

## Peta perkembangan project

```text
Jobsheet 01
HTML statis
   ↓
Jobsheet 02
HTML + CSS
   ↓
Jobsheet 03
HTML + CSS + Responsive
   ↓
Jobsheet 04
Rancangan UI/UX + Wireframe
   ↓
Jobsheet 05
+ JavaScript untuk interaksi
   ↓
Jobsheet 06
+ JSON + Fetch API + render dinamis
   ↓
Vercel
Project diakses melalui deployment dan router
```

## Cara menjawab soal UTS

Kalau dosen menunjukkan satu potongan kode, jangan langsung menghafal. Tanyakan 4 hal:

1. **Kode ini berada di mana?** HTML, CSS, JS, JSON, PHP, atau konfigurasi?
2. **Kode ini mencari/mengubah apa?** Misalnya `querySelector()` mencari elemen, `classList.toggle()` mengubah class.
3. **Kapan kode berjalan?** Saat halaman dimuat, tombol diklik, form disubmit, atau data selesai di-fetch.
4. **Apa hasil akhirnya?** Misalnya menu terbuka, baris terhapus, tabel terisi JSON, atau request diarahkan router.
