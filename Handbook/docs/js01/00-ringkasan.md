# Jobsheet 01 — HTML Dasar

## Gambaran

Jobsheet 01 adalah fondasi SIMPUS-Mini. Semua halaman masih **HTML statis**. Belum ada CSS khusus, JavaScript, JSON, database, atau server-side processing.

## Halaman

```text
Jobsheet1/
├── index.html
├── anggota/
│   ├── list.html
│   └── tambah.html
└── buku/
    ├── list.html
    └── tambah.html
```

Ada dua kelompok data: **buku** dan **anggota**. Masing-masing memiliki halaman daftar dan halaman tambah.

## Materi inti

- Struktur dokumen HTML5.
- Elemen semantik: `header`, `nav`, `main`, `section`, `footer`.
- Link antarhalaman dengan `href`.
- Tabel menggunakan `table`, `thead`, `tbody`, `tr`, `th`, `td`.
- Form menggunakan `form`, `label`, `input`, dan `button`.
- Atribut `id`, `name`, `for`, `type`, dan `required`.

## Hal yang harus dipahami untuk UTS

**HTML bukan bahasa untuk mengatur tampilan secara detail.** HTML menentukan struktur dan makna konten. Tampilan baru diperkuat pada Jobsheet 02 menggunakan CSS.
