# JS01 — Cheat Sheet UTS

| Kode | Fungsi |
|---|---|
| `<!DOCTYPE html>` | Menetapkan dokumen HTML5 |
| `<title>` | Judul tab browser |
| `<a href="...">` | Link/navigation |
| `<table>` | Tabel |
| `<thead>` | Header tabel |
| `<tbody>` | Isi/data tabel |
| `<tr>` | Baris |
| `<th>` | Cell header |
| `<td>` | Cell data |
| `<form>` | Wadah input |
| `<label for>` | Label yang terhubung ke `id` input |
| `required` | Field wajib diisi |
| `type="submit"` | Tombol submit form |
| `../` | Naik satu folder |

### Kalimat hafalan

> **HTML membangun struktur, bukan mempercantik tampilan.**

> **`thead` = kepala tabel, `tbody` = isi tabel.**

> **`id` mengidentifikasi elemen; `name` memberi nama field form.**
