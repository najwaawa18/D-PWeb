# JS04 — Cheat Sheet UTS

- **UI** → tampilan dan komponen yang digunakan pengguna.
- **UX** → pengalaman pengguna saat berinteraksi untuk mencapai tujuan.
- **Wireframe** → kerangka struktur halaman.
- **User flow** → urutan langkah pengguna.
- **Prototype** → simulasi interaksi/desain yang lebih mendekati pengalaman nyata.

### Urutan berpikir

```text
Masalah pengguna
      ↓
Kebutuhan
      ↓
User flow
      ↓
Wireframe
      ↓
UI visual
      ↓
Implementasi HTML/CSS/JS
```
