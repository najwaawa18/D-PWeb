# JS04 — Konsistensi Desain

Desain baru harus terasa sebagai bagian dari SIMPUS-Mini yang sama.

## Yang dipertahankan

- warna maroon;
- tipografi yang konsisten;
- bentuk navbar;
- gaya tombol;
- bentuk tabel;
- spacing/padding;
- kartu statistik;
- layout sederhana dan responsive.

## Contoh penerapan

Jika JS01–03 sudah memakai:

```text
Maroon + cream + white
```

maka halaman Dashboard baru sebaiknya tidak tiba-tiba menggunakan:

```text
Neon green + dark purple + font berbeda total
```

Secara teknis mungkin bisa, tetapi secara UX identitas aplikasi menjadi tidak konsisten.

## Prinsip UTS

Saat ditanya kenapa desain dibuat konsisten, jawabannya bukan sekadar "biar bagus". Konsistensi mengurangi beban belajar pengguna karena pola tombol, warna, navigasi, dan layout tetap dapat diprediksi.
