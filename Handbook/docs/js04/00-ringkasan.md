# Jobsheet 04 — UI/UX dan Wireframe

## Tujuan

JS04 fokus pada **perancangan sebelum implementasi**. Jadi jangan mencari perubahan kode besar seperti pada JS02/03. Source utama berisi `docs/wireframe.md` dan `infografis.png`, sedangkan implementasi halaman masih meneruskan fondasi SIMPUS-Mini.

## Konsep

- UI = User Interface, apa yang dilihat/digunakan pengguna.
- UX = User Experience, bagaimana pengalaman pengguna saat mencapai tujuan.
- User flow = urutan langkah pengguna.
- Wireframe = rancangan kasar struktur halaman.
- Konsistensi = halaman baru tetap mengikuti bahasa visual yang sudah ada.

## Rancangan yang dibahas

Wireframe mencakup contoh halaman seperti Login, Dashboard Petugas, Peminjaman, Pengembalian, dan Riwayat Peminjaman.

## Prinsip penting

Wireframe **bukan desain final**. Wireframe memprioritaskan struktur, hierarki informasi, navigasi, dan fungsi.
