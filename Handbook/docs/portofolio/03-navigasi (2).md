# Portfolio — Struktur

Portfolio menggunakan halaman utama `index.html`, stylesheet `style.css`, dan JavaScript `app.js`.

Struktur utama yang terlihat pada source:

```text
D-PWeb/
├── index.html
├── style.css
├── app.js
├── Jobsheet1/ ... Jobsheet13/
├── Jobsheet New/
└── Handbook/
```

Halaman portfolio membagi isi menjadi tiga kategori:

1. **Learning Process** — Jobsheet 01–08.
2. **Main Project** — Cafe_Najwa.
3. **Project Development** — Jobsheet 09–13.
