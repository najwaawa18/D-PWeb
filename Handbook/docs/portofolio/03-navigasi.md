# Portfolio — Navigasi

Portfolio menggunakan tombol kategori dengan `data-target` untuk menentukan panel yang dibuka.

Contoh:

```html
<button
    class="category-card"
    data-target="learningPanel"
>
```

Kategori yang tersedia:

- `learningPanel`
- `mainProjectPanel`
- `developmentPanel`

Setiap panel memiliki tombol kembali:

```html
<button class="back-btn">
    ← BACK TO CATEGORIES
</button>
```
