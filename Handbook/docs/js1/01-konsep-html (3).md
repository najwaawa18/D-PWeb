# Jobsheet 01 — Form Tambah Data

## 1. Form Anggota

Form tambah anggota berisi:

- Nama
- No. Anggota
- Alamat
- No. HP
- Tombol Simpan

Contoh:

```html
<label for="nama">Nama</label>
<input type="text" id="nama" name="nama" required>
```

`required` membuat input wajib diisi.

## 2. Form Buku

Form tambah buku berisi data buku seperti judul, pengarang, tahun terbit, ISBN, stok, dan kategori sesuai struktur halaman yang dibuat pada Jobsheet 01.

## 3. Catatan

Pada Jobsheet 01, form masih berupa **antarmuka HTML statis**. Tombol Simpan belum mengirim data ke server/database karena form belum memiliki proses backend.
