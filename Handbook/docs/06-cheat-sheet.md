# 06 — Cheat Sheet

| Konsep | Ingat |
|---|---|
| PDO | PHP ↔ database |
| prepare | siapkan query |
| execute | jalankan query + parameter |
| fetch | satu row |
| fetchAll | banyak row |
| fetchColumn | satu nilai |
| ILIKE | search case-insensitive PostgreSQL |
| LIMIT | jumlah data |
| OFFSET | data yang dilewati |
| password_hash | hash password |
| password_verify | verifikasi password |
| session | menyimpan state login |
| session_regenerate_id | ganti ID session |
| htmlspecialchars | escape output HTML |
| CSRF | lindungi request perubahan dari request lintas situs |
| beginTransaction | mulai transaction |
| commit | sahkan transaction |
| rollBack | batalkan transaction |
| FOR UPDATE | lock row |
| PK | identitas record |
| FK | hubungan antar tabel |
| UNIQUE | cegah duplikat |
| CHECK | batasi nilai |
