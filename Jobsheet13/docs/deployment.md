# Deployment Cafe_Najwa

## Platform
- Vercel: deployment aplikasi
- Supabase: PostgreSQL database

## Checklist
- [ ] Database Supabase aktif
- [ ] Environment variable sudah diatur
- [ ] Aplikasi dapat dibuka melalui URL Vercel
- [ ] Login berhasil
- [ ] CRUD master data berhasil
- [ ] Transaksi pesanan berhasil
- [ ] Pembayaran berhasil
- [ ] Status meja berjalan sesuai alur
- [ ] Laporan dapat dibuka
